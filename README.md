## What I'm building

**EXCSLA** makes verified business facts something AI systems can read, trust,
and surface to buyers. Two products on one platform:

- **AI Passport** — your business's authoritative, verified, machine-readable
  identity for AI.
- **Advisor Wiki** — turns an advisor's source material into an interrogable
  expert.

The platform is one .NET repository with bounded contexts that stay separate and
integrate only through explicit contracts.

- **[`MasterSkriptor/excsla-command`](https://github.com/MasterSkriptor/excsla-command)** —
  the EXCSLA Command Center: source of truth for code, architecture,
  documentation, infrastructure-as-code, and agent instructions.
- **[`MasterSkriptor/excsla-ai-auditor`](https://github.com/MasterSkriptor/excsla-ai-auditor)** —
  AI visibility audit tooling for the platform.
